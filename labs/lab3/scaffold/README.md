# Рабочая директория — Лаб 3 (CI/CD + DevSecOps)

Здесь ты строишь конвейер доставки для example-voting-app. Workflow-ы кладёшь в
`.github/workflows/`. Проверки смотрят на состав конвейера (стадии, сканеры-гейты,
стратегия тегов), а не на точный YAML — раскладку выбираешь сам.

В терминале инициализируй репозиторий:

    git init && git add . && git commit -m 'feat: ci pipeline'
