# Лаб 4 — harness (для преподавателя)

Автопроверка к капстоуну «Infrastructure as Code, наблюдаемость, надёжность»,
Раздел 4 (двойной вес). Общий фреймворк — [`../CLAUDE.md`](../CLAUDE.md). Пакет
самодостаточный, движок (`labs/trainer/`) подхватывает его автоматически.

## Модель

Субстрат — **Terraform (+ Ansible) + Prometheus/Grafana + документы SLO/ADR**.
Terraform может поднимать `kind`-кластер (провайдер kind/docker) — тогда виджет
статуса кластера в тренажёре применим. Студент декларативно поднимает инфраструктуру
и разворачивает example-voting-app. «Проверить» валидирует исход (validate,
идемпотентность/дрейф, наблюдаемость, SLI/SLO, ADR), не текст HCL — контракты
method-blind.

Автопроверка — ворота допуска, не балл. Балл на защите (см. `../CLAUDE.md`).

## Файлы

| Путь | Роль |
| --- | --- |
| `seed.py` | ИСУ → параметры варианта (canary, SLO-цель, ресурсы) |
| `content.py` | заголовок, задания, подсказки по контрактам, ярлыки |
| `checks/lib.sh` + `checks/NN_*.bats` | контракты (bats, TAP, ASCII-имена; к сервисам — foreground `inpod`) |
| `scaffold/` | дерево рабочей директории (`main.tf`, `playbook.yml`, `slo.yaml`, `adr/`) |
| `Makefile` | `seed` / `check` / `check-suite` / `clean` |
