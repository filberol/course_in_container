# solution/ — эталонное решение (только для преподавателя)

Ответ к Лаб 2 и средство самопроверки harness. **В шаблон, раздаваемый студентам,
этот каталог не входит** — удаляйте его при генерации студенческого репозитория.

Шаблоны в `manifests/` параметризованы сидом: `${NS}`, `${CANARY}`,
`${REPLICAS_VOTE}`, `${PVC_SIZE}`, `${MAX_UNAVAIL}`. Отрендерить и прогнать
контракты для конкретного варианта:

```bash
make selftest ISU=<ису>      # render + kubectl apply + make check
```

или по шагам:

```bash
python3 solution/render.py --isu <ису>
kubectl apply -f solution/rendered/
make check ISU=<ису>
```

Решение намеренно использует Deployment+PVC для БД, а не StatefulSet — контракты
задания 2 слепы к способу, оба варианта проходят. Это и демонстрирует студентам
принцип «проверяется исход, а не реализация».
