# Рабочая директория — Лаб 2

Здесь ты строишь решение. Раскладка файлов свободная (проверки смотрят на состояние
кластера, а не на текст манифестов) — можешь менять структуру как удобно.

Поднять и применить (в терминале ниже):

    kind create cluster --name lab2
    kubectl apply -f manifests/

Заготовки сервисов — в `manifests/` (пока только комментарии с подсказками).
