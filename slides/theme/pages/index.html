Практикум Лабораторные — развёртывание workspace

Единый тренажёр для всех лабораторных работ.

  1. Склонируй репозиторий курса и перейди в каталог labs/.
  2. Установи зависимости. Выбери свою операционную систему:
    macOS

    Если Homebrew ещё не установлен:

    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

    Затем установи необходимые инструменты:

    brew install docker kind kubectl bats-core jq ttyd
brew install --cask docker

    Запусти Docker Desktop и дождись, пока Docker станет доступен.

    Linux (Ubuntu/Debian)

    Установи базовые зависимости:

    sudo apt update
sudo apt install -y docker.io kubectl jq bats

    Установи kind и ttyd:

    curl -Lo ./kind https://kind.sigs.k8s.io/dl/latest/kind-linux-amd64
chmod +x ./kind
sudo mv ./kind /usr/local/bin/kind

curl -Lo ./ttyd.tar.gz https://github.com/tsl0922/ttyd/releases/latest/download/ttyd.x86_64.tar.gz
tar -xzf ./ttyd.tar.gz
sudo mv ./ttyd.x86_64 /usr/local/bin/ttyd

    Добавь текущего пользователя в группу Docker:

    sudo usermod -aG docker "$USER"

    После этого выйди из системы и войди снова либо выполни newgrp docker.

    Если в репозитории уже предусмотрена автоматическая установка, можно вместо ручной установки выполнить: 

    make setup
  3. Запусти тренажёр: 
    make trainer
    и открой http://localhost:8899.
  4. Выбери лабораторную работу в селекторе и укажи свой номер ИСУ — задания и файлы автоматически подставятся по варианту.
  5. В терминале подними кластер и применяй манифесты. Редактируй файлы слева и после выполнения задания нажимай «Проверить это задание».

Быстрый старт — если все зависимости уже установлены: 

git clone <репозиторий курса> && cd course_in_container/labs
make setup
make trainer
